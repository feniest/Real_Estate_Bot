
📂 Структура проекта

Для корректной работы приложения структура файлов в рабочей директории должна выглядеть следующим образом:


EstateProject/
├── config.ini          # Текстовый конфигурационный файл сети и лимитов
├── main.py             # GUI Панель оператора/администратора (PyQt6)
├── bot.py              # Telegram-бот (aiogram v3)
├── app_icon.ico        # Кастомная иконка для .exe (подготавливается вами)
└── estate.db           # Единая локальная база данных SQLite (создается сама)
